Отправка Email и Telegram-сообщений пользователям или участникам A/B тестов.

📖 Как создать рассылку:
  1. Нажмите «+ Новая рассылка» для разовой отправки всем или участникам конкретного A/B теста.
  2. Нажмите «A/B Пара», чтобы создать две кампании с разными текстами для вариантов A и B одного теста.
  3. После создания кампания имеет статус «Черновик» — нажмите «▶ Отправить» для немедленной отправки.
  4. Для просмотра статистики нажмите «📊 Статистика» рядом с кампанией.
